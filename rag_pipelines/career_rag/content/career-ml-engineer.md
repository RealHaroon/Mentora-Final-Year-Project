career: "ML Engineer"

A Machine Learning Engineer takes models — often developed by a data
scientist or researcher — and builds the production systems that train,
deploy, serve, and monitor them reliably at scale. The role is closer to
software engineering than data science: the core question isn't "what
pattern does this data show," it's "how do we run this model reliably,
quickly, and cheaply for real users."

**Typical required skills:** strong Python, deep learning frameworks
(TensorFlow, PyTorch), MLOps practices (versioning datasets and models,
automated retraining pipelines, monitoring for model drift), containerization
(Docker), and solid general software engineering — system design, APIs,
testing — since an ML engineer is responsible for code that other
engineers and real users depend on, not just a one-off notebook.

**Typical entry path:** a computer science or software engineering
background, often starting as a general software engineer or backend
engineer, then specializing into ML infrastructure as interest and
opportunity align. Some data scientists also move into this role once
they want to focus more on the engineering/deployment side than on
building models from scratch. Open-source contributions to ML tooling
projects are a strong, visible way to demonstrate this skill set without
needing prior ML-engineer job experience.

**How it differs from a Data Scientist role:** a data scientist is
usually judged on model accuracy and the insight it produces; an ML
engineer is usually judged on the system's reliability, latency, and cost
— a "good enough" model that runs fast and never crashes is often more
valuable in this role than a marginally more accurate model that's slow
or fragile.
