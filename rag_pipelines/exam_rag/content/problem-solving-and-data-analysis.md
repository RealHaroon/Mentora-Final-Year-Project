This topic covers applying math to real-world data — reading and
interpreting graphs/tables, working with ratios, rates, and percentages,
and basic statistics, rather than pure abstract algebra.

**Ratios, rates, and proportions.** A ratio compares two quantities
(e.g. 3:2); a rate compares two quantities with different units (e.g.
km/hour). In a proportional relationship, y = kx for some constant k —
doubling x always doubles y. Many real-world "find the missing value"
problems are solved by setting up a proportion: a/b = c/d, then
cross-multiplying.

**Percentages.** Percentage change = (new value − old value) / old
value × 100. A common trap: a 20% increase followed by a 20% decrease
does NOT return to the original value, because the second 20% is taken
from a larger (post-increase) base.

**Reading graphs and tables.** For a linear relationship shown as a
table of (x, y) pairs, the rate of change (slope) is
Δy/Δx — find it using any two rows, then use it to write an equation
y = mx + b (b is the value when x = 0, i.e. the "starting point" or flat
fee in a real-world context like a cost table).

**Basic statistics:**
- **Mean**: the sum of all values divided by how many there are.
- **Median**: the middle value when data is sorted (average the two
  middle values if there's an even count).
- **Mode**: the most frequently occurring value.
- **Range**: the difference between the highest and lowest values — a
  simple measure of spread.

Scatter plots show the relationship between two variables; a trend line
summarizes the overall pattern (positive, negative, or no correlation),
but correlation alone doesn't prove one variable causes the other.
