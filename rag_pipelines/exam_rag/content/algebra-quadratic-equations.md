A quadratic equation is any equation that can be written in the standard form
ax² + bx + c = 0, where a, b, and c are constants and a ≠ 0. The "quadratic"
name comes from "quad," meaning square — the defining feature is the x² term.
Because the highest power of x is 2, a quadratic equation has at most two
solutions (also called roots), which are the values of x that make the
equation true.

There are three common methods to solve a quadratic equation:

1. **Factorization** — rewrite ax² + bx + c as a product of two binomials,
   e.g. x² − 5x + 6 = 0 becomes (x − 2)(x − 3) = 0, giving roots x = 2 and
   x = 3. This only works cleanly when the expression factors nicely with
   integer or simple fractional roots.
2. **Completing the square** — rearrange the equation into the form
   (x + p)² = q, then take the square root of both sides. This always works,
   and is the method used to derive the quadratic formula itself.
3. **The quadratic formula** — the general solution for any quadratic
   equation: x = (−b ± √(b² − 4ac)) / 2a. The term under the square root,
   b² − 4ac, is called the discriminant. If it's positive, there are two
   real roots; if zero, exactly one (a repeated root); if negative, the
   roots are complex (not real numbers).

**Worked example:** Solve x² − 5x + 6 = 0.
Using the quadratic formula with a = 1, b = −5, c = 6:
discriminant = (−5)² − 4(1)(6) = 25 − 24 = 1.
x = (5 ± 1) / 2, so x = 3 or x = 2 — matching the factorization result above.

**Worked example 2:** Solve 2x² + 3x − 2 = 0.
discriminant = 3² − 4(2)(−2) = 9 + 16 = 25, so √25 = 5.
x = (−3 ± 5) / 4, giving x = 0.5 or x = −2.
