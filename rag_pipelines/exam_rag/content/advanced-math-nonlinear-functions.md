A nonlinear function is any function whose graph is not a straight line —
meaning the rate of change between inputs and outputs is not constant.
Common nonlinear function families include:

- **Quadratic functions**: f(x) = ax² + bx + c. The graph is a parabola —
  a U-shape (opening upward if a > 0, downward if a < 0). The vertex (the
  highest or lowest point) occurs at x = −b / 2a.
- **Exponential functions**: f(x) = a·bˣ, where b is the base (b > 0,
  b ≠ 1). These grow (if b > 1) or decay (if 0 < b < 1) by a constant
  *multiplicative* factor each step, rather than a constant additive
  amount like a linear function — this is what makes exponential growth
  eventually outpace any polynomial growth.
- **Rational functions**: a ratio of two polynomials, e.g. f(x) = 1/x.
  These often have **asymptotes** — lines the graph approaches but never
  touches. f(x) = 1/x has a vertical asymptote at x = 0 (undefined there)
  and a horizontal asymptote at y = 0 (the function approaches but never
  reaches 0 as x grows large).
- **Square root / radical functions**: f(x) = √x. The domain is restricted
  to x ≥ 0 (for real-valued outputs), since negative numbers don't have
  real square roots.

**Key skill: reading behavior from an equation, not just a graph.** For a
quadratic ax² + bx + c, the sign of a tells you whether it opens upward
(minimum point) or downward (maximum point), and the discriminant
(b² − 4ac) tells you how many times it crosses the x-axis — two times if
positive, once if zero, zero times if negative.

**Worked example:** Find the vertex of f(x) = 2x² − 8x + 3.
x = −b / 2a = −(−8) / (2·2) = 8/4 = 2.
f(2) = 2(4) − 16 + 3 = 8 − 16 + 3 = −5.
The vertex is at (2, −5), and since a = 2 > 0, this is the function's
minimum point.
